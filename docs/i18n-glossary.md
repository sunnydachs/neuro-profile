## Neural systems (neuro), used as canonical names everywhere
- 報酬・動機づけ系 (reward) → Reward & Motivation System
    region: 腹側線条体を中心とする報酬回路 → "reward circuitry centred on the ventral striatum"
    description: 目標や報酬に向かって働きかける傾向 → "a tendency to pursue goals and rewards"
- 警戒・脅威処理系 (vigilance) → Vigilance & Threat-Processing System
    region: 扁桃体を含む → "includes the amygdala"
    description: 危険や不確実な手掛かりへの敏感さ → "sensitivity to danger and uncertain cues"
- 実行制御ネットワーク (executive) → Executive Control Network
    region: 前頭前野・頭頂葉 → "prefrontal and parietal cortex"
    description: 計画・集中・抑制の傾向 → "a tendency for planning, focus and inhibition"
- デフォルトモード (dmn) → Default Mode Network
    region: 内側前頭・後帯状皮質など → "medial frontal and posterior cingulate cortex, among others"
    description: 内的思考・想像・振り返りの傾向 → "a tendency for inner thought, imagination, reflection"
- サリエンス／内受容系 (salience) → Salience / Interoceptive System
    region: 島皮質・前帯状皮質 → "insula and anterior cingulate cortex"
    description: 身体感覚や重要情報への気づき → "awareness of body sensations and salient information"
- 社会認知ネットワーク (social) → Social Cognition Network
    region: 側頭頭頂接合部など → "temporo-parietal junction, among others"
    description: 他者の気持ちや視点を読む傾向 → "a tendency to read others' feelings and perspectives"
- 情動調節系 (emotion_reg) → Emotion Regulation System
    region: 前頭−辺縁調節回路 → "fronto-limbic regulation circuitry"
    description: 気持ちの揺れからの回復・安定 → "recovering from and stabilising emotional swings"
