# 脳キャラ デザイン設計（部位別テンプレート）

> 16タイプの脳キャラ画像を、各タイプの対応ブライン部位（region）に応じて
> 「形」と「役割のアクセント」を変えて生成するための設計図。
> 共通タッチ（ぷにぷに白クリーム・点目だけ・かわいく親しみやすい）は維持する。

## 共通ルール（全タイプ）

- ベース：白〜クリームのぷにぷにした「脳ブロブ」（全体が脳のしわを想起させる凹凸）
- 顔：小さな黒い点目だけ（口・手・足なし）
- 質感：もちもち・マシュマロ・ソフトマット＋わずかなハイライト
- 背景：各グループの淡色（EI/EA=オレンジ系、VI/VA=ブルー系の淡色）
- 文字なし

## 部位 → 形テンプレート（解剖学的形をデフォルメ）

| 部位 | 解剖学的形 | キャラの形（デフォルメ） |
|---|---|---|
| 扁桃体（amygdala） | 小さめ・アーモンド形・左右対 | 丸っこいアーモンド/豆型。コロンと小さい。 |
| 前頭前野（prefrontal/DLPFC） | 脳の前部・額の裏・大きな表面 | 横に広い大きな曲面。ゆったりとした前面。 |
| 島皮質（insula） | 深部・しわに隠れた「島」 | 中央が深く折り込まれた「島」状のくぼみ。 |
| 腹側線条体（striatum/側坐核） | 基底核・報酬中枢・小さめ | 小さめの丸い塊。ぷっくりした粒。 |
| 後帯状皮質（DMN/内側前頭） | 内側・帯状回 | ゆるやかな内側のカーブ。静かな曲線。 |
| 側頭頭頂接合部（social） | 側頭〜頭頂の境目 | なだらかに流れる接合ライン。柔らかな二重構造。 |
| 帯状回・前帯状皮質（salience） | 内側の弧・注意切替 | 細長い弧を描く形。しなやかな弓。 |

## 部位 → 役割アクセント（色・模様）

| 部位 | 役割 | アクセント |
|---|---|---|
| 扁桃体 | 警戒・脅威検知 | くすんだ青紫の小さな「注意マーク」的な光点 |
| 前頭前野 | 計画・実行制御 | 橙〜青の規則的な小さなグリッド/回路線 |
| 島皮質 | 身体感覚・内受容 | 淡い緑の波紋/同心円 |
| 腹側線条体 | 報酬・動機 | 暖かい橙色の光点（ぴかっと光る粒） |
| 後帯状皮質 | 内省・DMN | 星空のような淡い金の点 |
| 側頭頭頂接合部 | 社会認知・共感 | やわらかなピンク〜コーラルの輪 |
| 前帯状皮質 | 注意切替・サリエンス | 白〜銀の「＋」や光の交差点 |

## 注意

- 実は8タイプが「前頭前野」（EA/VA系）になる。形の差が乏しくなるので、
  前頭前野グループ内でも「回路線の色（橙=探索/青=警戒）と密度」で差を出す。
- 腹側線条体3タイプ（EINS/EIXS/EIXD）も同様に、アクセントの光点の「数・配置」で
  わずかに差をつける（ノイズ対策も兼ねる）。
