# STEP 5 — スコアリングアルゴリズムの数学的仕様

> 目的：回答から「各軸スコア → 16 タイプ判定 →（結果ページ用）神経システム関連スコア」
> までを実装可能なレベルで数学的に定義する。

---

## 1. 入力

各質問 Q_k（k=1..50）への 5 段階リッカート回答を r_k ∈ {1,2,3,4,5} とする。

質問は 3 群に分かれる：
- **正規項目**：Q1〜Q40（各軸 8 問）
- **検証項目**：Q41〜Q50（タイプ判定には使わない）

---

## 2. 予備処理

### 2.1 逆転項目の反転
各軸に割り当てた逆転項目（◀ 印）について、回答を反転する：

```
s_k = r_k            （正規方向項目）
s_k = 6 - r_k        （逆転項目）
```

反転後の s_k ∈ {1..5} は、「軸の正方向の極」が高いほど 5 に近づくように揃える
（例：軸1 では E=探索・報酬接近が 5 方向、軸5 では T=ゆれ小が 5 方向）。

### 2.2 欠損回答
- 未回答項目が 2 問以下なら、その軸の平均スコアで補完する（mean imputation）。
- 3 問以上の未回答 → 当該軸を「診断不能」とし、後述の信頼度を下げる。
- 全 50 問中 10 問以上未回答 → 全体を診断不能として結果を出さない。

---

## 3. 軸スコアの計算

各軸 d ∈ {軸1..軸5} について、正規項目（8 問）の反転後スコアの平均を取る：

```
AxisScore_d = (1/n_d) × Σ_{k∈d} s_k    n_d = 8
```

これを 5 段階から 0〜100 の「プロフィール得点」へ線形変換する：

```
P_d = (AxisScore_d - 1) / (5 - 1) × 100   ∈ [0, 100]
```

（AxisScore_d=1 → P_d=0、5 → P_d=100。段階の中央 3 → 50。）

**両極の解釈**：
- P_d > 50 → 軸の「正方向」極に寄る（例：軸1 は探索）。
- P_d < 50 → 「負方向」極に寄る（例：軸1 は警戒）。
- P_d ≈ 50（例：45〜55）→ 明確な指向なし＝「両立的/中間」として扱う。

---

## 4. 極性の判定と 16 タイプ判定

### 4.1 極性の二値化
主要 4 軸（軸1〜4）の P_d から、タイプコードの各文字を決める：

```
bit = HIGH  if P_d ≥ 55
bit = LOW   if P_d ≤ 45
bit = MID   otherwise（45 < P_d < 55）
```

- 軸1：HIGH=E / LOW=V
- 軸2：HIGH=I / LOW=A
- 軸3：HIGH=N / LOW=X
- 軸4：HIGH=S / LOW=D
（対応は STEP 3 のコード定義に一致。軸5 はタイプ決定に使わない。）

### 4.2 明確性（distinctness）の扱い
- 4 軸すべてが HIGH か LOW に決まる（MID なし）→ **明瞭タイプ**。
- いずれかの軸が MID（45<P<55）→ その文字は**タイプ決定に使わない**が、
  結果ページでは「この軸は中間的」と明示する。
  - 実装：MID の軸は、後述の「最近傍タイプ」決定を実施し、結果に
    「あなたは◯◯型に近いが、この軸は中間的」と注記。

### 4.3 最近傍タイプ判定（typology nearest-type）
MID が生じた場合、16 タイプそれぞれとの「距離」を計算して最小距離のタイプを提示する：

```
distance(type_t) = Σ_{d=軸1..4} ( P_d - centroid_{t,d} )²
centroid_{t,d} = 100 if タイプの当該文字が HIGH 極, 0 if LOW 極
```

最も distance が小さいタイプを結果タイプとする。ただし距離の僅差（例：
第1位と第2位の差が閾値未満）なら「◯◯型と△△型の境界的傾向」と併記する。

## 5. 神経システム関連スコア（結果ページ「働きやすい神経系」用）

STEP 1 の 7 系統の神経システムについて、軸スコアから関連度を計算する：

| 神経システム | 対応する軸（得点源） |
|-------------|---------------------|
| 報酬・動機づけ系 | 軸1（探索側）+ 軸2（直感/即応の一部） |
| 警戒・脅威処理系 | 軸1（警戒側、逆転）|
| 実行制御ネットワーク | 軸2（分析側）+ 軸5安定（負荷小） |
| デフォルトモード（内的思考） | 軸3（内的側）+ 軸5（反芻、負方向） |
| サリエンス/内受容 | 軸2（直感/身体感覚） |
| 社会認知ネットワーク | 軸4（共感側） |
| 情動調節系（安定） | 軸5（ゆれ小側） |

変換式（各神経システム j について）：

```
NeuroScore_j = clamp( base + Σ_d w_{j,d} × (P_d - 50), 0, 100 )
```

- w_{j,d} は重み（-1..+1、下表で固定）。base は中立的基準値（50）。
- clamp で 0〜100 に収める。

### 重みテーブル（初期値。後続で検証・調整）

| 神経システム \ 軸 | 軸1 | 軸2 | 軸3 | 軸4 | 軸5 |
|-------------------|-----|-----|-----|-----|-----|
| 報酬・動機づけ | +0.8 | +0.3 | 0 | 0 | 0 |
| 警戒・脅威処理 | −0.8 | 0 | 0 | 0 | −0.2 |
| 実行制御 | 0 | +0.7 | 0 | 0 | −0.3 |
| DMN/内的思考 | 0 | 0 | +0.8 | 0 | −0.4 |

| 情動調節（安定） | 0 | 0 | 0 | 0 | +0.9 |

## 6. 信頼性の評価

### 6.1 一貫性（内的一貫性の代理）
- 各軸 8 問のうち、同方向文ペア（例：Q9 と Q12 はともに I 側）の回答差の絶対値を集計。
- 平均差が大きい（例：同一方向文で片方 5・片方 1）→ 一貫性が低い。
- 一貫性係数として Cronbach 的な粗指標ではなく、簡易に
  `Consistency = 1 - (平均|s_k - s_k'| / 4)` を参考値算出（後続の因子分析で正式化）。

### 6.2 社会的望ましさスコア
Q41〜45 の回答を集計：
- 「完全に誠実」「一度も後悔したことがない」等に 4〜5 を付けた数を数える
  （Q42/44/45 は順方向、Q41/43 は極端値そのものを検出）。
- 高得点 → 回答全体を社会的望ましさ方向に歪めている可能性 → 結果に「謙虚に
  回答した方が精度が上がります」等の注記。

### 6.3 注意散漫・中央寄り
- 中央寄り：全項目で「3」が 60% 超 → 「やや全体をダイレクトに選んだ可能性」。
- 極端連打：全項目で「1」か「5」が 70% 超 → 極端回答傾向。

### 6.4 総合信頼度
```
Reliability = f(未回答数, 一貫性, 社会的望ましさ, 中央/極端傾向)
```
→ 「高 / 中 / 低」の 3 段階で結果ページに表示。低の場合でも診断は行うが、
   結果の冒頭に注意を付す。

---

## 7. 診断不能ケース

以下のいずれかに該当する場合、タイプ判定を出さず「回答を見直してください」
等の再回答フローへ誘導する：

1. 全 50 問中 10 問以上の未回答
2. 一貫性照合（Q46/47 相当）で、同義文ペアの回答が両極端（5 と 1）に分裂
3. 注意散漫フラグ（Q41/43 など improbable 文に「非常に当てはまる」）が複数
4. 単一回答を機械的に連打（全項目同一値）した痕跡

---

## 8. 出力

```
回答 → 逆転処理 → 軸スコア(0-100) ×5 → 
     → 極性二値化 → 16タイプ判定（+ 境界注記）
     → 神経システム関連スコア(0-100) ×7
     → 信頼度（高/中/低）+ 各注意フラグ
```
