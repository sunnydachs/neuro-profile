# タイプ × 脳部位 マッピング案（叩き台）

> 目的：16タイプそれぞれに「関連する神経システム」と「その中枢に関わる脳部位」を
> 併記し、「このタイプの脳はこの辺りが関係しそう」という"脳感"を出す。
> ただし service.md の最重要ルール（推定表現の厳守）を守る。
>
> ＝ 確定事項ではなく、「こういう見せ方ができそう」という提案の叩き台。

## 前提（科学的整合性）

- 既存 types.json の neuro_top3 は「神経システム／ネットワーク名」で表記済み。
  これは科学文献で確立した概念であり、そのまま保持する。
- 各システムには「中心となる脳部位」が研究で関連付けられている。これを
  「豆知識」として**併記**するのは妥当（ただし「この部位が実際に活発」と
  断定はしない。あくまで「関連が研究されている部位」として提示）。

## 神経システム → 代表的な脳部位（標準的な対応）

| 神経システム（既存表記） | 代表的な脳部位 | 役割（ざっくり） |
|---|---|---|
| 報酬・動機づけ系 | 線条体・側坐核・腹側被蓋野 | 報酬・やる気・接近 |
| デフォルトモード（DMN） | 内側前頭前野・後帯状皮質・頭頂葉 | 内省・想像・自己参照 |
| サリエンス／内受容系 | 島皮質・前帯状皮質 | 身体感覚・注意の切り替え |
| 実行制御ネットワーク | 背外側前頭前野・前帯状皮質 | 計画・実行・抑制 |
| 警戒・脅威処理系 | 扁桃体・海馬 | リスク察知・記憶 |
| 社会認知ネットワーク | 側頭頭頂接合部・内側前頭前野 | 共感・他者理解 |
